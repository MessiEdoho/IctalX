Notes

  1. Top bar. Stays fixed on scroll. Links jump to sections 01 to 03. Contact jumps to the cite block.
  2. Hero. One-line purpose and a short description. The trace is decorative and stops moving when the user prefers reduced motion.
  3. Recording card. States in W2 to W5.
  4. Summary card. Empty until a detection run. Then shows length, events, ictal time, confidence, reviewed, confirmed, rejected and the analysis ID.
  5. Review workspace. Hidden until detection completes. See W6.
  6. Pipeline. Four steps in plain words. Full parameters are referred to the paper.
  7. Test data and offline use. Sample files and a guide for running the app locally.
  8. Cite and footer. Citation, BibTeX with copy button, contact, licence and the research-use disclaimer. No edit mode toolbar.

Notes

  1. Format switch. EDF or CSV. Switching clears the chosen file and fields.
  2. Privacy line. Exact wording: “Your file is processed and then deleted.”
  3. Drop zone. Drag and drop or click. Accepts .edf in EDF mode. Keyboard: Enter or Space opens the file picker.
  4. File chip. Name, size and remove button.
  5. Channel. Filled from the EDF header, read in the browser. Multi-channel files are accepted; only the chosen channel is analysed. Nothing is uploaded yet.
  6. Header values. Read-only, shown so the user can check them before running.
  7. Detect seizures. Enabled once a file and channel are set. Uploads the file and starts the run (W5).

Notes

  1. Session notice. Shown once per session. There is no database; results live in server memory until the session expires.
  2. Downloads. events.csv, or a .zip with events.csv, summary.json and a waveform and spectrogram image per event.
  3. Filter and sort. Filter by status. Sort by onset or probability.
  4. Event table. Scrolls inside its own panel. The selected row is marked. Up and Down keys move between events.
  5. Descriptors. Peak amplitude, kurtosis, skewness and envelope. Definitions to be supplied (TBC). Probability is the mean over the event.
  6. Waveform. Preprocessed signal (notch, DC removal, robust z-score) of the chosen channel, from 120 s before onset to 120 s after offset. Built from the same 40-segment blocks as detection. The event selected in the table is highlighted. Time labels at both ends.
  7. Spectrogram. Same window as the waveform, preprocessed signal, 0 Hz to the Nyquist frequency (fs / 2; 250 Hz at 500 Hz). A red rectangle outlines the seizure. Settings as in missed_seizure_audit.py: 1 s windows, 75% overlap.
  8. Decision. Confirm or Reject sets a draft. Pressing the active choice again clears it. Shortcuts C and R.
  9. Save. Saves the draft. While a draft is unsaved the marker shows, and moving away opens W8. Shortcut S or Enter.

Notes

  1. Padding. This event starts 34.85 s into the recording, so only 34.85 s of the 120 s before onset exist. The missing 85.15 s is padded and shown hatched, labelled “No data”. The same applies at the end of a recording.
  2. Same layout every time. Because of the padding, the seizure always sits at the same place on screen, which makes events easy to compare. Report images follow the same rule.

Unsaved decision prompt

Modal over the review workspace
Unsaved decision

Event 2 is marked Confirmed but not saved. What would you like to do?

Stay Discard Save

Notes

  1. When it appears. The reviewer selects another event, or uses Up or Down, while a draft is unsaved. Focus moves into the prompt; Escape equals Stay.
  2. Choices. Save keeps the decision and moves on. Discard drops the draft and moves on. Stay closes the prompt and keeps the current event. Save is the default button.

Leaving the page

Closing or reloading the tab with an unsaved draft or with results not yet downloaded triggers the browser's own leave-page warning. Its wording cannot be changed.
